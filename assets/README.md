# 放你自己的模型

本仓库**不包含模型和贴图**。把模型放这里：

```
assets/
├── model.pmx
└── tex/          ← PMX 内部引用的贴图路径要保持一致
```

或者用环境变量指定：

```bat
set PET_MODEL=D:\models\your.pmx
python pet.py
```

## 为什么不在仓库里

MMD 模型（尤其是游戏角色模型）通常有严格条款：

- 禁止二次配布
- 禁止商用
- 角色版权归原厂（如 miHoYo / Hoyoverse）
- 部分允许改色/修权重，但禁止拆件移植到别的模型

**开源代码 ≠ 开源模型。** 请自备模型并遵守原作者许可。
